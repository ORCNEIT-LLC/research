# ORCNEITGPT — исследования

[English](README.en.md)

Здесь собраны три научно-инженерные публикации ORCNEIT Lab о работе над языковой моделью ORCNEITGPT. В каждой — условия эксперимента, измерения, выводы и ограничения. Таблицы доступны в CSV, графики построены по тем же значениям.

ORCNEITGPT находится в исследовательской разработке. Завершённый запуск обучения не означает, что модель прошла проверку качества или готова к публичному использованию.

## Публикации

| Работа | Наблюдения | Основной результат |
| --- | --- | --- |
| [Обучение языковой модели с нуля](papers/ru/language-model-pretraining.md) | 22–23.08.2026 | 80 000 шагов, 327,68 млн предъявленных токенов; совокупная проверка качества не пройдена |
| [Дообучение для диалога](papers/ru/dialogue-fine-tuning.md) | 23.08.2026 | Правильных ответов стало 43 из 256 вместо 0; критерии приёмки ассистента не достигнуты |
| [Пересборка обучающей основы](papers/ru/rebuilding-the-training-foundation.md) | 20.08–26.09.2026 | Измерены изменения токенизации и оценщика; подготовка нового корпуса ещё не завершена на дату наблюдений |

## Что показывают эти результаты

Это отчёты о собственных экспериментах ORCNEIT, а не сравнение с коммерческими моделями или независимая оценка. Снижение ошибки предсказания, уменьшение повторов и ускорение оценщика — разные результаты; ни один из них отдельно не доказывает качество готового ассистента.

327,68 млн токенов — число предъявлений при обучении, включая повторы, а не размер уникального корпуса. В проверке диалога 256 результатов получены на 128 заданиях в двух режимах генерации. Цель в 4 млрд токенов не означает, что этот объём уже собран или использован для обучения.
